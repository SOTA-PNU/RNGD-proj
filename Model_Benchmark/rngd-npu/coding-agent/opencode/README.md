# opencode

opencode is an interactive CLI tool designed to assist with software engineering tasks. It provides features such as code searching, file editing, task automation, and integration with various development tools.

## Features

- **Code Search**: Quickly find files and code snippets using `glob` and `grep` tools.
- **File Editing**: Modify files with precise string replacements using the `edit` tool.
- **Task Automation**: Automate complex workflows with the `task` tool.
- **Integration**: Works seamlessly with Git, npm, and other common development tools.
- **Help & Feedback**: Use `/help` for assistance or report issues at [GitHub Issues](https://github.com/anomalyco/opencode/issues).

## Usage

To get started, use the following commands:

- `opencode help`: View available commands.
- `opencode [command]`: Execute specific tasks (e.g., `opencode grep "pattern"").

For detailed guidance, refer to the [documentation](https://opencode.ai).
