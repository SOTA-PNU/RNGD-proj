# ACCV 2026 논문 프로젝트

이 폴더는 ACCV 2026(제18회 아시아 컴퓨터비전 학회, 오사카 12월)에 낼 논문 *"Where Vision Breaks First"* 의 주제·실험 계획·기술 해설을 모아 둔 작업 폴더입니다.

**논문 한 줄 요약.** 멀티모달 트랜스포머(VLM, 예: Qwen3-VL)를 퓨리오사 RNGD NPU(LLM·트랜스포머용 저정밀 추론칩)에서 돌리면, 칩이 강제하는 저정밀(FP8/MXFP4) 경로에서 **언어 디코더보다 "비전 타워"가 먼저 무너진다**는 것을 실제 실리콘에서 측정·국소화하고, per-channel·per-block 가중치접기 스케일로 시각 정확도를 되살립니다.

## 한눈에
- **학회:** ACCV 2026, 오사카, 12월. 본 트랙 제출 7월 5일. 트랙: Optimization Methods.
- **결정권자 더블 직격:** Jiwen Lu(VLM 양자화 Q-VLM·efficient ViT), Hyunjung Shim(diffusion PTQ DGQ, "진단 먼저→고치기"). 둘 다 직격하는 주제입니다.
- **왜 VLM인가(칩 정체성):** RNGD는 1세대 비전칩 Warboy의 후속이 **아니라** 2세대 **LLM·트랜스포머·멀티모달** 추론칩("Tensor Contraction Processor")입니다. CNN을 올리는 건 칩의 존재 이유에 안 맞습니다. VLM은 RNGD의 본령이고, 벤더 SDK가 **실제로 구현한 유일한 비전 모델이 Qwen3-VL**입니다.
- **해자(novelty):** VLM 양자화 연구는 거의 다 *시뮬레이션 bit-op*으로 측정합니다. 우리는 **실제 닫힌-컴파일러 상용 NPU 실리콘**에서 측정하고, 붕괴를 **비전 타워로 공간적으로 국소화**합니다 — 커뮤니티가 지적하는 sim↔배포 공백을 정통으로 칩니다.
- **⚠️ 최대 리스크:** 이 레포에서 비전 모델이 RNGD에 올라간 적이 한 번도 없습니다(아티팩트 18개 전부 LLM). 그래서 **첫 행동 = E0 게이트**(Qwen3-VL의 첫 on-NPU forward를 띄우는 것). 안 되면 host-loop 폴백 + 진단-only로 축소.

## 자주 받는 질문

**Q. 왜 CNN 주제를 버렸나?** (1) 순수 CNN은 연구계에서 dated하고, (2) 더 결정적으로 RNGD는 CNN/비전칩(Warboy)이 아니라 LLM/트랜스포머 칩입니다. LLM 칩에 CNN을 올려 벤치마크하는 건 틀린 서사라, 같은 "정밀도 붕괴" 지적 자산을 **VLM의 트랜스포머 비전 타워로 이식**했습니다(CNN 결과는 intro 한 문단 동기부여로만).

**Q. RNGD에서 비전이 되긴 하나?** LLM/트랜스포머는 이미 잘 돕니다(Qwen3-32B·Coder-30B-A3B 등 다수 서빙). VLM(Qwen3-VL)은 SDK에 구현돼 있으나 이 머신에서 아직 안 띄워봤습니다 → E0 게이트로 확인 중. 순수 CNN(MobileNet)은 컴파일·실행되나 학습모델 정확도 붕괴, ResNet/YOLO는 풀링으로 막힘(`../../info/README_vision_compile.md`).
