## Title
```
Do Not Merge the Registers: Register-Aware Reduction for Extreme Token Compression in Vision Encoders with Registers
```

## Keywords (쉼표 구분)
```
token reduction, token merging, vision transformers, register tokens, DINOv2, training-free, efficient inference
```

## TL;DR (한 문장)
```
Protecting register tokens during token merging keeps register-equipped vision encoders accurate under extreme (~92%) token compression, with no training.
```

## Abstract
```
Foundation vision encoders such as DINOv2 and CLIP are widely reused as off-the-shelf feature extractors, but processing hundreds of tokens makes inference costly. Token merging or pruning lowers this cost, yet existing methods rank token importance with generic similarity or energy heuristics. Some of these encoders concentrate global information in a few register tokens, and we observe that standard size-weighted merging removes these register tokens under extreme compression, with a large accompanying accuracy drop. We therefore study a simple, training-free change: protect the register tokens and aggressively merge only the remaining patch tokens. On a register-equipped DINOv2-ViT-B/14 with 4 registers, evaluated by kNN top-1 (val leave-one-out) on the full 50,000-image ImageNet-1k validation set, protecting registers retains 71.86% at ~92% token reduction, whereas the unprotected ToMe drops to 63.99%, a +7.87 gap. In a same-budget comparison with the closest competitor, official PiToMe, PiToMe is stronger at moderate compression, but under extreme compression register protection surpasses it: the crossover is at ~74% tokens / ~35% FLOPs, reaching +3.2 at ~92%, with slightly higher throughput. Equal-count random, energy, and high-norm alternatives stay within the measurement noise of the unprotected baseline. Unlike RegCache, which prefixes registers for quantization, and FNA, which approximates attention, we use registers as a keep-prior for sequence-length reduction. On ADE20k linear-probe segmentation the same protection improves mIoU at every reduction ratio, reaching +3.1 at ~91%, whereas the alternative priors do not help. As the method is deterministic, we quantify uncertainty by bootstrapping the evaluation set; the 95% confidence interval of the gain excludes 0 at every reduction ratio. Our quantitative headline is a single encoder, DINOv2-ViT-B/14 with a single seed; ViT-S/L extensions and linear probing are reported over 3 seeds, and the gain is model-dependent. On-chip (NPU) acceleration is future work; GPU throughput is measured.
```
