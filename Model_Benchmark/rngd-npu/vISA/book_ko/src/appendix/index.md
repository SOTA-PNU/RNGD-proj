# 부록

다음 절들은 Furiosa IR Optimizer 를 보완하는 개발 도구의 참고 자료다.

- [`cargo-furiosa-opt`](./cargo-furiosa-opt.md): 툴체인을 구동하는 cargo 서브커맨드 — 백엔드 선택, 자동 커널 빌드, 직접 컴파일러 모드.
- [언어 서버](./language-server.md): IDE 통합을 위한 `furiosa-rust-analyzer-proxy` 의 설치와 설정.
- [Schedule Viewer](./schedule-viewer.md): 스케줄 JSON 파일을 살펴보는 대화형 뷰어.
